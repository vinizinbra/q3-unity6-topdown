# Power upgrades atlas

`PowerUpgradesAtlas.svg` is a flat geometric 6x4 atlas. Each cell is 128x128.

| Row | Cells, left to right |
|---|---|
| 1 | Weapon Damage, Fire Rate, Reload Speed, Magazine Size, Critical Chance, Critical Damage |
| 2 | Weapon Range, Projectile Speed, Max Health, Toughness, Movement Speed, Health Regeneration |
| 3 | Healing Received, Pickup Radius, Dash Cooldown, Dash Charge, Skill Damage, Skill Cooldown |
| 4 | Skill Duration, Skill Area, Hero Skill Charge, Experience Gain, Luck, Coin Gain |

Dash Invulnerability is omitted because it is not an implemented upgrade. Rift Shard Gain is a Rift Mutation currency effect, not a Global Power upgrade.
